# Consistly.ai – Manual Software Testing Project

## Project Overview

This project contains manual testing documentation for Consistly.ai.

The purpose of this project was to test the application's functionality,
identify defects, and document the testing results.

## Application Tested

Website: Consistly.ai

## Testing Activities

- Checker Screen
- Test Checklist
- Test Cases
- Bug Reporting
- Functional Testing
- UI Testing
- Validation Testing
- Authentication Testing
- Data Testing
